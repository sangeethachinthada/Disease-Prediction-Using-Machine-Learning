# 🩺 Disease Prediction Using Machine Learning

## Project Description

Disease Prediction Using Machine Learning is a healthcare-based Machine Learning project that predicts the possible disease based on patient symptoms and health information.

The system takes patient details such as Age, Gender, Symptoms, and Symptom Count as input. The trained Machine Learning model analyzes the given information and predicts the most probable disease.

This project demonstrates the application of Artificial Intelligence and Machine Learning techniques in the healthcare domain.

---

## Objectives

- Predict diseases based on patient symptoms.
- Build a Machine Learning classification model.
- Analyze patient health data.
- Provide accurate disease predictions.

---
